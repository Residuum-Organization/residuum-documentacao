# Pesquisa — proposta de piloto inicial

[Voltar ao índice de pesquisas](README.md)

## 1. Objetivo

Testar a cadeia completa em escala pequena antes de ampliar funcionalidades ou cobertura.

## 2. Escopo sugerido

- operação em Manaus;
- poucos pontos de coleta;
- uma ou duas cooperativas;
- PET e alumínio;
- número limitado de moradores;
- período de teste fechado;
- sistema de pontos simples;
- pequeno catálogo de benefícios;
- dashboard básico.

## 3. Fluxo a validar

**morador → registro → escolha do ponto → descarte → validação → pontos → armazenamento → solicitação de retirada → cooperativa → pesagem → registro → dashboard**

## 4. O que medir

### Morador

- taxa de cadastro;
- taxa de primeiro descarte;
- recorrência;
- tempo até descarte;
- uso de recompensa;
- abandono.

### Ponto de coleta

- frequência de entregas;
- materiais;
- ocupação;
- tempo até retirada;
- facilidade de operação.

### Cooperativa

- tempo de resposta;
- deslocamento;
- volume;
- peso;
- inconsistências;
- facilidade do fluxo.

### Dados

- completude;
- precisão;
- divergência entre declarado e pesado;
- eventos sem validação;
- atualização;
- rastreabilidade.

## 5. Critério de sucesso

O piloto deve responder três perguntas:

1. A operação funciona de ponta a ponta?
2. Os usuários e parceiros realmente utilizam o fluxo?
3. Os dados gerados são confiáveis e úteis o bastante para apoiar decisões?

O piloto não precisa provar escala estadual. Precisa provar a cadeia básica.
