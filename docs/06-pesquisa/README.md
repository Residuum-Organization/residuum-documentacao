## Como usar

- **Pesquisa** registra hipóteses, referências externas, entrevistas e análises.
- **Visão** descreve a proposta atual do produto.
- **Requisitos** registra comportamento acordado.
- **Planejamento** organiza execução.
- Uma descoberta de pesquisa só deve virar requisito depois de decisão explícita da equipe/idealizador.

## Conclusão estratégica atual

A pesquisa indica que pontos de coleta, recompensas, integração com cooperativas e geração de dados **não são, isoladamente, diferenciais exclusivos**.

A principal hipótese de posicionamento discutida é:

> **Residuum como infraestrutura operacional e de dados para a cadeia de reciclagem do Amazonas, com rastreabilidade granular e inteligência útil para empresas e poder público.**

Essa formulação continua sendo uma hipótese a validar.
