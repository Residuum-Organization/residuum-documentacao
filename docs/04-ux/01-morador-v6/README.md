## Contexto dos artefatos

JSONs, capturas e patch foram preservados byte a byte. Os caminhos dentro do patch descrevem a árvore do frontend na versão de origem, não a localização atual desta documentação. Referências a testes em `tmp/morador-v6` registram o ambiente usado na entrega e não são comandos de reprodução deste repositório.
